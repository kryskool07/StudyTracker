# StudyTracker

StudyTracker is a small project I made to make it easier for students to keep track of subjects, tasks and deadlines.
The website is written in Norwegian and is mainly aimed at Norwegian students.
Users can add subjects, create tasks with deadlines, mark tasks as completed and see their overall progress.
The project is built with plain HTML, CSS and JavaScript.

## Features

- Add and delete subjects
- Edit subject names
- Add comments and deadlines
- Add tasks to each subject
- Set deadlines for tasks
- Mark tasks as completed
- See progress for each subject
- See total progress
- Show when a task is overdue

The data is stored in the browser using LocalStorage, so it is saved even if the page is closed.

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## How to run the project

Download the project and open `index.html` in your browser.
No extra installation is needed.
